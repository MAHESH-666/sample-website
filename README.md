# Sample Static Website

A minimal multi-page HTML website with home, about, and contact pages.

## Pages

- `index.html` — home page
- `about.html` — about page
- `contact.html` — contact page

## Technology

- HTML5
- Relative links between static pages

## Run locally

Open `index.html` in a modern browser. No build tools or server-side runtime are required.

## Scope

This is a basic HTML navigation exercise. It does not include a contact-form backend, data storage, user accounts, or a content-management system.
